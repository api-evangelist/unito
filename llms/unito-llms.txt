# Unito

> Unito is a two-way sync and integration platform that keeps work items in sync across 60+ SaaS tools (Asana, Jira, Trello, GitHub, Azure DevOps, ServiceNow, Salesforce, Smartsheet and more) with no-code field mappings and rules. Developers can build custom connectors with a TypeScript SDK and CLI, embed Unito's sync UI in their own product (Sync Embed), and drive embeds programmatically with the Unito Embed API. SOC 2 Type 2 certified.

Generated by API Evangelist from the Unito developer surface (no /llms.txt is published by Unito as of 2026-07-21).

## APIs

- [Unito Embed API documentation](https://dev.unito.io/docs/embeds/embedApi/): REST API for embedding partners - workspace management and usage reporting. Base URL https://api.unito.io, X-API-Key header authentication.
- [Unito Embed API reference (Swagger UI)](https://api.unito.io/embeds/docs/): interactive OpenAPI-based reference.
- [Unito Embed API OpenAPI 3.0.3](https://api.unito.io/embeds/docs/openapi.json): machine-readable spec.

## Developer Platform

- [Developer portal](https://dev.unito.io/): Unito developer documentation home.
- [Welcome / getting started](https://dev.unito.io/docs/intro/): entry point to the docs.
- [Build a connector](https://dev.unito.io/docs/connectors/getStarted/): connectors are HTTP servers exposing a graph of items and relations per Unito's API specification.
- [Connector API specification](https://dev.unito.io/docs/category/api-specification/): credential account, data types, graph operations, health, and webhook operations a connector implements.
- [Connector SDK](https://dev.unito.io/docs/connectors/SDK/getStarted/): npm install @unito/integration-sdk
- [Connector CLI](https://dev.unito.io/docs/connectors/CLI/getStarted/): npm install --global @unito/integration-cli
- [Sync Embed](https://dev.unito.io/docs/embeds/getStarted/): embed Unito's two-way sync UI in any app via iframe (https://app.unito.io/api/embed/<embed-id>).
